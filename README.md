## 📂 Extraction Location

Inside the official installation directory, the icons were extracted from:

```path
android-studio/plugins/android/lib/artwork.jar -> icons/versions/
```

> **Note on Version Changes:**
> In Android Studio 2.3.3, these assets were located in `android.jar`. Beginning with Android Studio 3.2.1, they were moved to `artwork.jar`.
