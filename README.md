# Android Version Icons (Bugdroid Icons)

This repository contains historical Android version logos and Bugdroid mascot icon assets extracted directly from the official Android Studio distribution.

## 📦 Source Details

* **Source**: Official Android Studio 3.2.1 Linux package (`android-studio-ide-181.5056338-linux.zip`)
* **Release Date**: October 11, 2018
* **SHA-256 Checksum**: `b9ec0d44f2feaafe1e3fbd1ed696bf325f9e05cfb6c1ace84dbf87ae249efa84`

## 📂 File Location Path

The location of the version icons changed between Android Studio releases:

* **Android Studio 2.3.3 and earlier**: Located inside `android.jar`
* **Android Studio 3.2.1**: Moved to `android-studio/plugins/android/lib/artwork.jar` under the directory `icons/versions/`
