# Android 历史版本图标集 (Bugdroid Icons)

本仓库包含了从官方 Android Studio 安装包中提取的历代 Android 版本标志与 Bugdroid 吉祥物图标资源。

## 📦 资源来源

* **提取来源**：官方 Android Studio 3.2.1 Linux 安装包 (`android-studio-ide-181.5056338-linux.zip`)
* **发布时间**：2018 年 10 月 11 日
* **SHA-256 校验**：`b9ec0d44f2feaafe1e3fbd1ed696bf325f9e05cfb6c1ace84dbf87ae249efa84`

## 📂 文件路径变化

在 Android Studio 的不同版本中，版本图标的存放位置有所调整：

* **Android Studio 2.3.3 及更早版本**：位于 `android.jar` 内部。
* **Android Studio 3.2.1**：迁移至 `android-studio/plugins/android/lib/artwork.jar`，具体目录为 `icons/versions/`。
